# 硬件清单、接线和组装

本表描述当前源码支持的接口，不是已采购/已验证的器件清单。收到板卡后先逐项比对；焊接、供电规格和原理图无法仅凭软件检查确定。

## 物料与兼容条件

| 模块 | 当前支持条件 | 采购/到货需要记录 |
| --- | --- | --- |
| 主控 | ESP32-S3，当前继承的16MB Flash / 8MB PSRAM配置 | 模组丝印、Flash/PSRAM类型、原理图、引出脚、USB数据能力 |
| 屏幕 | I2C SSD1306 128×64，地址0x3C | 实际芯片、尺寸、接口电平 |
| 麦克风 | 当前驱动为数字I2S输入，如历史方案INMP441/ICS43434接口 | 模块电压、左右声道选择和引脚标识 |
| 功放/喇叭 | 独立I2S输出，历史方案为MAX98357A接口 | 功放额定电压、喇叭阻抗/功率与供电能力 |
| 底盘 | 左右直流减速电机，每侧两路方向输入的驱动模块 | 驱动真值表、3.3V输入兼容、PWM及堵转电流能力 |
| 软弹机构 | 飞轮电机 + 独立推弹舵机，俯仰可选 | 软弹规格、机械供弹方式、额定电压、电流、舵机行程 |
| 飞轮驱动 | 3.3V逻辑兼容的外接开关/驱动，控制端外部下拉 | 电机启动/堵转电流、散热、感性负载保护 |
| 确认按钮 | 独立低电平有效常开按钮 | 可靠接线，另一端接GND；不复用BOOT、聊天或音量键 |
| 电源与保护 | 主控、舵机和电机按各自额定值供电，共地 | 降压额定/峰值电流、开关、线径、接头极性和保护 |
| 工具/结构件 | 数据线、万用表、连接线、固定件、承接箱 | 是否已有，实际数量与成本 |

不要把开发板3.3V当作电机或舵机电源。2S电池若使用，标称7.4V、满电8.4V；是否可以直供每个器件必须查对应额定规格。不能凭“都是5V模块”推断大电流和共地已正确。

## 当前接线表

| 功能 | ESP32-S3 GPIO | 软件约定 |
| --- | --- | --- |
| 麦克风WS/SCK/DIN | 4 / 5 / 6 | 16kHz输入 |
| 功放DOUT/BCLK/LRCK | 7 / 15 / 16 | 24kHz输出 |
| OLED SDA/SCL | 41 / 42 | I2C0，0x3C，128×64 |
| 状态LED | 48 | 当前板型SingleLed |
| BOOT / 触摸对话键 | 0 / 47 | 配网/聊天；按住说话 |
| 音量增 / 减 | 40 / 39 | 点击调音量，长按最大/静音 |
| 灯控 | 18 | 原有灯工具；不应误接动力机构 |
| 底盘LF / LB / RF / RB | 12 / 13 / 14 / 21 | 左前/左后/右前/右后方向信号 |
| 飞轮 / 推弹 / 确认键 | 未配置（-1） | 炮塔默认禁用 |
| 可选俯仰 | -1 | 不安装时保持禁用 |

实际引脚以生成的配置与板级源码为准。炮塔候选扩展脚为8、9、10、11、17、38，必须互不重复并核对实际板卡；主机测试采用的8/9/11/10不能当成实物已经验证的接线方案。所有GND按驱动方案共地。

## 不接动力的组装顺序

1. 拍照记录所有型号、端子和原理图；核对当前驱动类型、Flash/PSRAM和引脚。
2. 仅接主控、屏幕和音频，不接电机、飞轮和舵机动力。确认USB串口并编译/烧录整套镜像。
3. 完成Wi-Fi、灵矽、语音和只读工具验证。记录STA MAC但不公开凭据。
4. 车轮悬空，单独验证底盘方向和低占空比输出；若电机极性反了，先断电再调整接线或配置，不靠提示词反转概念。
5. 炮塔无弹空载，先确认外部下拉与上电不启动，再逐项验证飞轮、推弹舵机和按钮，最后才启用组合序列。
6. 标定推弹脉宽和行程、预转/回位时长。若机构是电磁铁、继电器或单电机连续供弹，当前舵机驱动不适用，应先改适配而不是强行启用。
7. 完成异常取消与供电压力检查后，才进行人工监督下的软弹承接箱验证和录像。

## 参数调整入口

炮塔引脚、推弹时序、舵机脉宽端点和允许俯仰角可通过JSON预览/备份工具配置，步骤见 [硬件参数配置](build.md#硬件参数配置与完整检查)。默认配置仍禁用炮塔；只有完成器件核对才启用。软件检查不能替代实际接线和行程标定。

## 到货记录模板

复制到个人验收记录，逐项填写实际数据，不用猜测值替代：主控/屏幕/音频/驱动/机构型号；固件commit；设备MAC（共享记录可脱敏）；各路供电与峰值观察；GPIO接线；电机方向；推弹rest/push脉宽；预转/保持/回位时长；按钮效果；异常取消结果；操作者与时间。未通过项保留原始现象。

编译和烧录入口见 [运行说明](build.md)，炮塔限制见 [炮塔说明](turret-control.md)，逐项结果见 [验收矩阵](acceptance.md)。
