## 排错原则与回退

按供电/接线 → 本地固件 → Wi-Fi → 云端身份和配置 → 音频 → MCP → 动作适配逐层排查。先保存脱敏日志，区分“模型说了”“工具接受了”“物理动作发生了”。供电异常先断动力，不用不断重启掩盖现象。

云端不可用时可展示主机测试与架构，或在局域网调试入口实际可用后展示手动底盘；必须说明此时不是语音闭环。机构未通过时保持炮塔禁用，展示真实拒绝和取消状态，不能用剪辑或模拟冒充实机。
