# 实机 Demo 交付入口

状态：等待硬件到货、实机验收和真实录制。当前没有可宣称通过的实机视频。

录制脚本见 [演示说明](../docs/demo.md)。上传后在本文件记录：

| 字段 | 填写内容 |
| --- | --- |
| 视频位置 | GitHub仓库文件或本仓库Release资产的实际链接 |
| 固件版本 | 实际录制时的commit/tag，不移动v0 |
| 硬件 | 主控、底盘、驱动、音频和软弹机构实际型号 |
| 演示范围 | 语音、工具、底盘、确认/取消、异常场景实际覆盖情况 |
| 录制信息 | 日期、是否剪辑、原始连续录像位置 |
| 未通过项 | 如实列出，不把模拟或口头说明当作实物结果 |

不在此处放空视频文件或编造外链；源代码和测试可以提前交付，实机证据必须实录。
